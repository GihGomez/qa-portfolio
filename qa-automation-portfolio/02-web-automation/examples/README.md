# Exemplos de Automação

## Fluxo: Login com sucesso

### Pré-condição

Usuário válido cadastrado

### Passos

1. Acessar sistema
2. Informar usuário
3. Informar senha
4. Clicar em login

### Resultado esperado

Usuário autenticado com sucesso

---

## Fluxo: Checkout completo

### Pré-condição

Produto disponível

### Passos

1. Selecionar produto
2. Adicionar ao carrinho
3. Iniciar checkout
4. Informar dados
5. Confirmar compra

### Resultado esperado

Pedido finalizado com sucesso
