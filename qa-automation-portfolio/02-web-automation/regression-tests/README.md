# Regression Tests

Regression tests garantem que funcionalidades antigas continuam funcionando após mudanças.

## Cenários

| ID | Cenário |
|----|---------|
| RG-001 | Login inválido |
| RG-002 | Produtos |
| RG-003 | Carrinho |
| RG-004 | Checkout |
| RG-005 | Finalização |

## Estratégia

Executados:

- diariamente;
- antes de release;
- após grandes mudanças.
