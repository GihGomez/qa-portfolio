# Smoke Tests

Smoke tests validam rapidamente funcionalidades críticas.

## Cenários

| ID | Cenário |
|----|---------|
| ST-001 | Login válido |
| ST-002 | Logout |
| ST-003 | Adicionar produto |
| ST-004 | Checkout |

## Estratégia

Executados:

- a cada commit
- antes de merge
- antes de deploy
