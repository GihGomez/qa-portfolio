# Hooks

Hooks executam ações antes ou depois dos cenários.

## Tipos

### Before

Executado antes do cenário.

Exemplos:

- abrir navegador
- iniciar sessão
- preparar ambiente

### After

Executado após o cenário.

Exemplos:

- capturar evidências
- encerrar sessão
- limpar dados

## Benefícios

- padronização
- isolamento
- manutenção simplificada
