# Step Definitions

Step Definitions conectam os cenários Gherkin com o código automatizado.

## Responsabilidades

- mapear steps
- executar ações
- validar resultados

## Exemplo

### Given

Preparação do contexto.

### When

Execução da ação.

### Then

Validação do comportamento esperado.

## Boas práticas

- steps reutilizáveis
- nomes claros
- evitar duplicação
- foco no comportamento
