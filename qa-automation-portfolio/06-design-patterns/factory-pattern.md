# Factory Pattern

Factory centraliza a criação de objetos.

## Aplicação em automação

Criação de:

- browsers
- drivers
- ambientes
- usuários de teste

## Exemplo

Selecionar navegador:

- Chrome
- Firefox
- Edge

Sem alterar a lógica dos testes.

## Benefícios

✅ flexibilidade  
✅ desacoplamento  
✅ configuração centralizada
