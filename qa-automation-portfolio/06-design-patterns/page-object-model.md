# Page Object Model (POM)

POM separa a lógica da interface dos testes.

## Estrutura

Cada página ou tela possui:

- elementos;
- ações;
- validações.

## Exemplo

### LoginPage

Responsável por:

- preencher usuário
- preencher senha
- clicar em login

### CartPage

Responsável por:

- adicionar produtos
- remover produtos
- validar carrinho

## Benefícios

✅ menor duplicação  
✅ manutenção simplificada  
✅ maior legibilidade  
✅ reutilização
