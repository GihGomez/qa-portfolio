# Estratégia de Execução

Definição de quando e como cada suíte deve ser executada.

## Smoke Suite

Executada:

- a cada commit;
- antes de merge.

### Objetivo

Validar funcionalidades críticas.

---

## Regression Suite

Executada:

- diariamente
- antes de release

### Objetivo

Garantir estabilidade geral.

---

## Full Suite

Executada:

- antes de produção.

### Objetivo

Validar cobertura completa.
