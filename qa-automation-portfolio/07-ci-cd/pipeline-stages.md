# Pipeline Stages

Etapas comuns de um pipeline de automação.

## 1. Checkout

Obtenção do código fonte.

---

## 2. Build

Compilação e preparação do projeto.

---

## 3. Test Execution

Execução das suítes automatizadas.

### Exemplos

- smoke
- regression
- API
- mobile

---

## 4. Report Generation

Geração de evidências.

### Exemplos

- logs;
- screenshots
- relatórios

---

## 5. Publish Results

Publicação dos resultados.

## Benefícios

- rastreabilidade
- transparência
- feedback contínuo
