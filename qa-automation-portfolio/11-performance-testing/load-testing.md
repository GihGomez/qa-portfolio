# Load Testing

Load Testing valida o comportamento do sistema sob carga esperada.

## Objetivo

Garantir que a aplicação suporta o volume normal de usuários.

## Exemplo

Sistema esperado:

500 usuários simultâneos.

## Cenário

Usuários executando:

- login
- navegação
- checkout
- consultas

## Validações

- tempo de resposta
- taxa de erro
- uso de recursos

## Benefícios

✅ validação do ambiente real  
✅ identificação de gargalos
