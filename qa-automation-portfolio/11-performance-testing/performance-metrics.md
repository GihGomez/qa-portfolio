# Performance Metrics

Métricas utilizadas para análise de desempenho.

## Response Time

Tempo de resposta da aplicação.

### Exemplo

500 ms.

---

## Throughput

Quantidade de requisições processadas.

### Exemplo

200 requests/segundo.

---

## Error Rate

Percentual de falhas.

### Exemplo

1%.

---

## Concurrent Users

Usuários simultâneos.

### Exemplo

1000 usuários.

---

## Resource Usage

Consumo de recursos.

### Exemplos

- CPU
- memória
- disco
- rede

## Objetivo

Identificar limites e gargalos do sistema.
