# Stress Testing

Stress Testing avalia o comportamento além do limite esperado.

## Objetivo

Descobrir o ponto de falha do sistema.

## Exemplo

Carga crescente:

500 → 1000 → 2000 usuários.

## Validações

- estabilidade
- recuperação
- degradação

## Perguntas respondidas

- quando o sistema falha?
- como ele se recupera?
- existe perda de dados?
