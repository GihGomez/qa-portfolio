# Tipos de Framework

Frameworks organizam e padronizam a automação.

## Linear

Scripts simples.

### Vantagens

- rápido para começar.

### Desvantagens

- baixa escalabilidade.

---

## Modular

Divide funcionalidades em módulos.

### Vantagens

- reutilização.

### Desvantagens

- exige maior planejamento.

---

## Data Driven

Separação entre lógica e massa de dados.

### Vantagens

- múltiplos cenários com pouco código.

### Exemplo

Login com:

- usuário válido
- senha inválida
- campos vazios

---

## Keyword Driven

Ações descritas por palavras-chave.

### Exemplo

- CLICK
- TYPE
- VALIDATE

---

## Hybrid Framework

Combinação de múltiplas abordagens.

### Vantagens

- maior flexibilidade
- melhor escalabilidade

É o modelo mais utilizado em projetos reais.
