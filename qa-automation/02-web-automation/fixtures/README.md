# Fixtures

Fixtures são dados e configurações utilizados antes da execução dos testes.

## Utilização

### Setup

Preparação do ambiente:

- abrir navegador
- configurar sessão
- limpar cookies

### Teardown

Finalização:

- capturar evidências
- encerrar navegador
- limpar contexto

## Benefícios

- padronização
- isolamento
- previsibilidade
