# Environments

Environments armazenam variáveis utilizadas pelos testes.

## Variáveis utilizadas

| Variável | Descrição |
|----------|-----------|
| baseUrl | URL base da API |
| token | Token de autenticação |
| userId | ID do usuário |
| timeout | Tempo máximo |

## Benefícios

- flexibilidade
- múltiplos ambientes
- fácil manutenção
