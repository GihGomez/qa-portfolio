## 🎯 Objetivo

Demonstrar conhecimentos em:

- escrita de cenários orientados ao negócio
- comunicação entre QA, desenvolvimento e produto
- automação baseada em comportamento
- reutilização de steps

## Benefícios do BDD

✅ linguagem acessível para negócio  
✅ documentação viva  
✅ maior colaboração entre times  
✅ cenários reutilizáveis
