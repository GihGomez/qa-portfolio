# Builder Pattern

Builder facilita a criação de objetos complexos.

## Aplicação em automação

Criação de:

- payloads
- usuários
- produtos
- massas de teste

## Exemplo

Usuário de teste:

- nome
- email
- senha
- perfil

## Benefícios

✅ dados legíveis  
✅ criação controlada  
✅ fácil manutenção
