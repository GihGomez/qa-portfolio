# Singleton Pattern

Singleton garante uma única instância de um objeto.

## Aplicação em automação

Utilizado para:

- WebDriver
- configurações
- conexões
- sessões

## Benefícios

✅ economia de recursos  
✅ controle centralizado  
✅ consistência de execução

## Cuidados

Uso incorreto pode gerar:

- dependência global
- problemas de paralelismo
