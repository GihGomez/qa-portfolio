# GitHub Actions

GitHub Actions permite automatizar execuções diretamente no repositório.

## Aplicações em QA

- execução a cada push
- execução a cada pull request
- execução agendada
- geração de relatórios

## Eventos comuns

### Push

Executa após envio de código.

### Pull Request

Executa antes do merge.

### Schedule

Executa em horários definidos.

## Benefícios

✅ integração nativa com GitHub  
✅ configuração versionada  
✅ fácil manutenção
