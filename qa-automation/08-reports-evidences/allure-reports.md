# Allure Reports

Allure é uma ferramenta para geração de relatórios de testes automatizados.

## Informações exibidas

- total de testes
- testes aprovados
- testes falhos
- tempo de execução
- histórico de execuções
- stack traces

## Benefícios

✅ visualização clara  
✅ histórico de resultados  
✅ suporte a investigação  
✅ integração com CI/CD

## Aplicações

Utilizado em:

- testes web
- testes API
- testes mobile
