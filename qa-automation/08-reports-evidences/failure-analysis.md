# Failure Analysis

Análise de falhas durante execuções automatizadas.

## Tipos de falha

### Defeito real

Erro da aplicação.

### Instabilidade de teste

Problemas no script.

### Ambiente

Problemas externos.

### Massa de dados

Dados inconsistentes.

## Processo de análise

1. identificar falha
2. analisar logs
3. validar evidências
4. reproduzir cenário
5. classificar causa raiz

## Objetivo

Separar:

- bugs reais
- flaky tests
- problemas de ambiente
