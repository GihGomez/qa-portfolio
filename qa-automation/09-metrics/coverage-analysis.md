# Coverage Analysis

Cobertura representa quanto do sistema está protegido pela automação.

## Tipos de cobertura

### Funcional

Fluxos de negócio.

### API

Endpoints críticos.

### UI

Jornadas do usuário.

### Regressão

Funcionalidades existentes.

## Exemplo

| Área | Cobertura |
|------|-----------|
| Login | 100% |
| Checkout | 95% |
| Carrinho | 90% |
| Cadastro | 85% |

## Objetivo

Identificar gaps e priorizar novos cenários.
