# Pairwise Testing

Pairwise reduz combinações testando pares de variáveis.

## Exemplo

Sistema suporta:

### Navegadores

- Chrome
- Firefox
- Edge

### Sistemas

- Windows
- macOS

### Idiomas

- PT
- EN

## Problema

Combinação total:

18 cenários.

## Solução

Pairwise reduz para um conjunto mínimo com alta cobertura.

## Benefícios

✅ menos testes  
✅ alta cobertura  
✅ menor tempo de execução

## Aplicação

Ideal para:

- cross-browser
- multi-device
- múltiplas configurações
