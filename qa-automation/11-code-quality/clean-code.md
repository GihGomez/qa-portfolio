# Clean Code

Clean Code torna automação mais legível e sustentável.

## Princípios

## Clareza

Código deve ser fácil de entender.

## Simplicidade

Resolver problemas com menor complexidade.

## Responsabilidade única

Cada componente deve possuir uma função clara.

## Reutilização

Evitar duplicação.

## Benefícios

✅ manutenção simplificada  
✅ menos bugs  
✅ evolução segura
