# QA Automation — Teste de Login

Projeto básico de automação de testes utilizando **Java, Selenium WebDriver, JUnit 5 e Maven**.

## Objetivo

Demonstrar conhecimentos básicos em automação de testes funcionais, incluindo:

* Abertura do navegador
* Localização de elementos
* Preenchimento de campos
* Execução de ações
* Validação de resultados
* Setup e teardown dos testes

## Tecnologias

* Java
* Selenium WebDriver
* JUnit 5
* Maven
* Google Chrome

## Cenário automatizado

**Login com credenciais válidas**

1. Acessar a página de login
2. Informar usuário
3. Informar senha
4. Clicar em Login
5. Validar acesso à página de produtos

## Execução

```bash
mvn test
```
